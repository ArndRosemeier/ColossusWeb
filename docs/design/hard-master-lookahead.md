# Hard masterboard expectimax

`ai/masterLookahead.ts:searchMasterMoves` is the production Hard depth seam. It uses three actual current legal noncombat move candidates, a two-endpoint beam at each future roll, all six movement faces, and two future own movement/muster cycles after the current landing. This is additional temporal depth; increasing a current candidate count alone is not this policy.

`evaluateMove.pickBestMove` still returns shared forced separation, risk-reducing Titan rescue and Easy coordination decisions first. It computes the unchanged ordinary Normal command once, with the ordinary RNG consumption. Normal/Easy immediately return it. For Hard, that command is included in the shortlist; current combat decisions stay with the existing scorer. Only a completely evaluated alternative with more than0.5 expected army-quality improvement can replace the control. Every Hard control also considers a legal completed HOLD counterfactual, so Hard can stop even when Normal proposes a worse move, and already-earned allied musters cannot falsely justify another move. Root HOLD may return Done only when the engine permits ending movement; otherwise it carries an actual companion move certificate. Exhaustion, insufficient improvement and unresolved existing combat all retain the exact ordinary control. Search itself consumes no RNG.

Each projected current landing clones owned legions/caretaker and runs deterministic greedy global muster using engine bestRecruit/scoreRecruitOption/applyRecruit. Already-moved allies compete for the same last copy. Future rounds reset ALL friendly movement/recruitment/teleport eligibility and owner teleport availability. Other positions remain frozen unless a concrete companion move certifies HOLD for the selected legion. Only genuinely moved stacks may muster, including the companion with shared caretaker depletion; stationary HOLD never grants a recruit. Legal future routes, blockers and each turn's teleport eligibility come from listMovePreview. Current command legality is checked with listAllMoves and the actual current roll. Current and future stock/composition changes are real projections, without mutating the input or dispatching commands into the live world.

A future frontier is ranked by the existing strategic recruit scorer before two successors are expanded. Every retained successor goes through the real recruit application. The expectimax maximizes legal projected continuations for each of six equally likely rolls, then averages those six outcomes. It values ability-aware creature strength, Titan power and a small available-development component for the entire friendly army, rather than counting raw chits. Current and future rounds share caretaker depletion. Greedy forecast is exact for Balanced's maximum-greed muster; other personalities can choose a near-best actual recruit later, so this remains an approximate forecast followed by replanning.

Survival uses six-roll enemy reach under the candidate occupancy and the shared battle estimate. Opposing legions of one owner share a roll, so their winning six-bit reach events are unioned per player, with independent remaining-player opportunities. `boardSpatial.candidateReachRollMasks` reuses the existing occupancy/teleport key and adds an optional bounded512-entry mask cache only for explicit callers; existing Normal/Easy count paths are unchanged. Stock-sensitive battle outcomes are recomputed separately. Current occupied-target normal movement stops on contact, producing nested suffix masks, so the former maximum would be equivalent there; this generic union is not claimed as an observed Default-game bug. Tests separate synthetic disjoint/overlap aggregation math from actual legal occupied-target masks and a caretaker-sensitive reinforcement outcome. Death removes the mover's projected quality; Titan death has a large game-loss cost. Forecast quality is discounted0.85 per future cycle. Combat destinations are not expanded into invented winners/casualties; a genuinely mandatory combat-only frontier receives no fabricated winning-combat credit. It is not deemed mandatory merely because the selected legion has only attack destinations: a bounded concrete noncombat companion move may permit the selected legion to HOLD. If other legal actions exist but no safe certificate is modeled, the comparison is incomplete and falls back instead of assigning fictitious selected-legion death. Truly immobile/legal-ending branches retain existing quality without an invented muster. This is a conservative local single-legion model, not full-game expectimax, a tactical battle simulator or fair-information inference.

Default work limits are600 unique evaluated nodes,6000 generated legal frontier options and4096 movement-provider queries, three current candidates and two future endpoints. The reach helper performs six-roll batches; its final batch may overshoot the query limit by at most six before the whole search is abandoned. Memo and reach caches are decision-local; memo keys include complete stock, every legion's occupancy/composition/hits/eligibility and all player score/Titan/teleport inputs. Variant and personality are fixed during a call. Partial chance nodes return no value, and an exhausted root comparison discards all partially comparable positive candidates. Counters expose requested/reached depth, nodes, memo hits, future musters/types, generated moves, actual movement queries and completion/exhaustion.

The old `musterSearch` modes are opt-in research policies with different scoring and incomplete cache keys. They deliberately remain unchanged here: silently routing them through the new search would violate the explicit Normal/Easy command/RNG preservation requirement. Production Hard is not mapped to unbounded lookplus. Legality and recruiting heuristics are shared engine seams, not reimplemented graph rules.
